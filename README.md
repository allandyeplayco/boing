# Boing

A slam-bounce platformer prototype. Boing bounces on his own and always moves sideways; tap anywhere to slam.

## Play it
Open `index.html` in a browser (it works on a phone too). No install or build step.

## What's here
- `index.html`: the whole game in one file.
- `art/boing/`: Boing's poses and character sheet.
- `docs/`: the design brief and screenshots.
- `levels/`: early level codes.
- `CLAUDE.md`: notes for Claude about how the game works.
