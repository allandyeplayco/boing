# Levels

Paste each level code you copied from the prototype (Edit → Level code → Copy) into its own file here, for example `early-01.json`, `early-02.json`.

These came from the first prototype and serve as examples of early levels. They are not the final level set.

To load one into the game by hand: open `index.html`, tap **Edit**, then **Level code**, paste the code, and tap **Load**.
